PJSIP native SDK for Windows x64

SIP TLS: enabled with OpenSSL
Audio backend: Windows Multimedia Extensions (WMME)
Compile-time log ceiling: 6
Integration: link from the Windows Flutter native plugin, then expose MethodChannel/EventChannel APIs
Dart FFI wrapper: not included
